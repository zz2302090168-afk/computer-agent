# 蓝屏、死机与随机重启

知识ID: support-bsod-restart
编写日期: 2026-09-09
类型: sol_general_guidance

## 适用范围与来源说明

适用于系统运行中蓝屏、画面冻结、自动重启或突然关机。本指导由 Sol 编写，未经具体厂家逐项验证，不对未核实错误码作固定解释。无外部网址来源。

## 症状区分

蓝屏有可记录文字；冻结通常画面停住且无响应；自动重启可能看不到提示；突然断电更接近供电或保护动作。偶发一次与固定负载下稳定复现的证据强度不同。

### 先问

询问错误文字和停止代码原文、发生时间与频率、当时运行的软件、是否只在游戏或高负载发生、近期驱动/系统/硬件变化、温度与风扇是否异常、是否伴随焦味异响、重要数据是否已保存。

### 步骤1：保存错误与复现条件

操作：拍下完整蓝屏文字，记录发生前正在做什么及是否自动重启；不要依据相似截图套用结论。预期结果：可判断错误和触发场景是否重复。请反馈：完整错误文字、当时任务和是否自动重启；收到结果后再决定下一步。

### 步骤2：查看系统可靠性记录

操作：在 Windows 搜索并打开“查看可靠性历史记录”，查看故障时间附近的应用或 Windows 失败项，只抄录名称、时间和摘要。预期结果：可能发现具体失败项，也可能只有“未正常关闭”。请反馈：对应时间的名称和摘要原文；收到结果后再决定下一步。

### 步骤3：撤销近期软件变量

操作：若问题紧随某个新应用、驱动或超频工具出现，先停用该应用的开机启动或使用其官方卸载入口撤销这一项，一次只改一个变量。预期结果：可能不再复现或继续发生。请反馈：撤销了哪一项、观察时长及是否复发；收到结果后再决定下一步。

### 步骤4：核对负载与温度关联

操作：使用系统已有监控或硬件厂商工具观察故障前温度、负载和风扇变化，不运行额外极限压力测试。预期结果：可判断故障是否只与高负载和温度变化同时出现。请反馈：工具与传感器名称、故障前读数和当时负载；收到结果后再决定下一步，其他部件仍需分别核实。

### 停止条件

伴随焦味、火花、异常高温、供电线缆变色、异响或反复快速重启时停止通电。重要数据未备份时，不反复制造蓝屏，不进行会大量写盘的压力测试。不得通过刷 BIOS、拆电源或随意加压来验证。

## 结论边界

单条事件记录、单次蓝屏或某个停止代码不足以确认故障件；应说明证据和待核实项。用户明确要求人工时记录请求，并说明当前真实人工入口未接通。
