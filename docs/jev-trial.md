# Jev 配置与可选入口路由

在本地 `.env.local` **追加**下面两项，不覆盖已有配置；本次代码改动不修改该文件。

```dotenv
TYPESAFE_API_KEY=填写你自己的TypeSafe密钥
TYPESAFE_MODEL=jev-latest
```

第二项可省略，默认 `jev-latest`。原有 `MODEL_*` 继续用于聊天，`EMBEDDING_*` 继续用于检索，不能用 Jev 密钥替换。不要使用 `NEXT_PUBLIC_` 前缀，不要把密钥提交 Git 或发到聊天里。

- `pnpm test:jev --check`：只检查本地密钥是否存在，不联网、不扣费；不验证密钥有效性。
- `pnpm test:jev`：调用官方 Jev 三次，测试全量分页、单页否定表达、查询与保存预算两个意图。发送的只有固定测试句与判断问题，不访问数据库，不执行业务工具，不自动重试。

脚本读取 `.env.local`，进程中已存在的同名环境变量优先。每次启动重新读取，无需重启网页。接口固定为 `https://api.typesafe.ai/v1/systemone`；30秒超时只适用于本试验，不改变主模型设置。错误不打印密钥、原始服务响应或请求头。

输出包含逐项判断概率、0.5阈值的样例通过情况、请求耗时与服务端Token统计（缺失为null）。这是独立冒烟测试，不是已经接入主流程，不证明线上收益，也不作为修改或确认配置的授权判断。

接口依据：[TypeSafe官方快速开始](https://docs.typesafe.ai/introduction/quickstart)。真实调用可能消耗赠送或付费额度，以账号计费为准。

## 聊天入口集成

已提供服务端可选开关 `JEV_ROUTER_ENABLED=true`，默认关闭。只有显式开启且配置了 `TYPESAFE_API_KEY` 才会调用。无需替换主模型；`.env.local` 仍由用户自己维护。

仅首次页面消息、无整机咨询附件、无售后上下文、长度不超过1000字符时尝试。仅对CPU、显卡或两者的无条件普通目录浏览生成固定只读计划；价格/型号/配色/数量/排序/分页、写操作、依赖及其他意图由原LLM规划。多轮消息不发送Jev，沿原流程处理，避免丢失上下文。

准入要求：eligible概率至少0.9、Choice置信度至少0.8、所选项概率至少0.9，概率字段和值域完整；这些是保守试验门槛，不是经过业务校准的正确率保证。输出仍经过set_request_action、注册表参数和权限校验，不能生成写工具。高置信度也可能错分，因此不宣称入口理解绝对可靠。

一次路由最长2秒，不重试；非2xx、无效响应、低置信度或不支持的任务全部回到原入口。此上限仅针对新增Jev调用，不改变已有模型超时或重试额度。用户取消会传播，不改成继续回退。发送内容仅当前用户消息与固定判断问题，不发送目录、模型密钥或对话历史。既有诊断链记录 `jev.route` 的原因、用量和耗时，密钥不进入调用记录。

## 对照命令

`node scripts/jev-comparison.mjs before`：全程关闭Jev，六类请求各一次，记录当前链路参考。`node scripts/jev-comparison.mjs`：六类场景各组三次，交替关闭/开启，共36次。每次新进程和固定测试目录；包含Jev耗时与回退开销，LLM/Jev调用及Token分别统计。生成manifest、原始samples、源码一致性校验、summary与报告；失败不删、不替换。

这些调用需要主模型及Jev配置并可能产生费用；不修改业务数据。不与之前50次旧版本消融样本合并，不以不同价格模型的Token总量冒充费用。单场景三次不足以证明稳定P95，整体为固定测试集等权汇总，不代表线上流量。

## 2026-09-21 接入对照结论：保留关闭

先记录 [未接入时六类各一次](../reports/jev-before-2026-09-21T04-59-06-887Z/report.md)，再进行 [正式36次开关对照](../reports/jev-comparison-2026-09-21T05-03-19-277Z/report.md)。基线是分页修复后的当前版本，不是早期存在漏分页问题的版本。正式采样期间所记录源码指纹一致。

| 指标 | 关闭 | 开启 |
|---|---:|---:|
| 程序断言通过 | 18/18 | 18/18 |
| 平均LLM调用 | 3 | 3 |
| 平均Jev调用 | 0 | 1 |
| 平均LLM Token | 31,175.5 | 31,185.8 |
| 平均Jev Token | 0 | 789.2 |
| 整体耗时中位数 | 11,024 ms | 12,727 ms |
| 整体P95（nearest-rank） | 19,793 ms | 27,321 ms |

开启后整体中位耗时约增加15.4%，没有减少LLM调用。单查询和带条件查询样本略快、双查询与依赖样本更慢；不能将这种小样本墙钟差异归因于Jev本身。新增路由一定增加了一次请求，但总耗时差异还包含主模型输出、网络和缓存波动。当前不证明全局收益，因此默认关闭，不为提高命中率事后降低门槛。

采样后额外做了一次只读诊断（不混入正式36次）：普通显卡目录请求的eligible=0.79；Choice为gpu、confidence=0.98、gpu概率=0.98。类别正确，但未达eligible>=0.9准入线，返回unsupported_or_uncertain。这解释该诊断请求的回退，不将其冒充每次请求都保存了分类概率。

接入不修改 `.env.local`；网页只有显式设置 `JEV_ROUTER_ENABLED=true` 才启用，单独配置密钥仍保持原流程。本轮不建议开启。保留集成和复现脚本，不改变现有预算、分页、权限校验或模型重试额度。真实测试使用固定商品夹具，不访问业务数据库，也未做页面端到端验证。
