# 商品身份 BM25 与品牌型号匹配

2026-09-22 将 `codex/rag-quality-llm-optimization` 工作副本中的商品身份 BM25、目录品牌别名匹配及对应测试合入桌面 `main` 工作区。后续同日又迁入 Ragas 与模型评测，统一在桌面维护；旧分支保留提交历史，旧工作目录不再使用。评测迁移见 `eval/rag/README.zh-CN.md`。

## 调用方式

`backend/rag/catalog-models.ts` 以本轮数据库目录为语料，用类别、品牌和完整型号计算 BM25（k1=1.2、b=0.75），支持英文数字词、中文双字、大小写和全角归一化。最多返回十二条商品身份记录，保留 ID、品牌、型号与演示标记。

结构化动作处于 `search_catalog` 或 `find_replacements` 时，召回记录进入模型上下文。入口规划和其他动作不注入这些记录；桌面现有 DAG、直执行及并行只读路径保留。直执行不会为了读取 BM25 证据新增模型调用。

`backend/services/catalog-search.ts` 从每条数据库记录的双语品牌字段派生中英文前缀，保留 Cooler Master 等完整英文品牌，不将 Intel 芯片平台猜成华擎板卡的商品品牌。剥离匹配的品牌前缀后，继续用原有型号规则匹配；容量、RTX/Ti 后缀及显式品牌、价格和颜色条件仍生效。

BM25 只提供身份线索，相关度不证明精确命中或兼容，也不授予替换和确认权限。商品审核仍由现有程序执行。本次未迁移旧副本的精确商品 ID 换件绑定、Ragas、模型评审或其他对话流程。
